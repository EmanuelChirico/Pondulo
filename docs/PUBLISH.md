# GitHub repository

Repository: [EmanuelChirico/Pondulo](https://github.com/EmanuelChirico/Pondulo).
The local clone retains the original `origin` remote and branch `main`.

## Publish local commits

From the repository root, with GitHub SSH access configured:

```sh
git push origin main
```

The Actions tab shows the host-test run after a push. The workflow runs the native software tests recorded in the validation guide.
